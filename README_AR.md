# NurseHub — Google Sheets CSV

## الملفات
- index.html: واجهة الموقع الأصلية كما هي.
- config.js: رابط الشيت المنشور وأسماء أوراق البيانات.
- api.js: قراءة الأوراق وتحويل CSV إلى بيانات يستخدمها الموقع.
- admin.html: صفحة إرشادية؛ التعديل الفعلي يتم داخل Google Sheets.

## النشر
ارفع الملفات الأربعة إلى جذر مستودع GitHub Pages واستبدل النسخ القديمة بها.

## ملاحظة مهمة قبل الاعتماد
تم ضبط القارئ على اختيار كل ورقة باسمها عبر `sheet=اسم_الورقة` في رابط النشر.
يجب التأكد أن Google Sheets نشر الأوراق السبع كلها ضمن Publish to web. إذا لم تُرجع ورقة معينة CSV، فسنحتاج روابط CSV المنفصلة أو قيم `gid` لكل ورقة من إعدادات النشر.

CSV للقراءة فقط: أضف وعدّل المحتوى من Google Sheets، ثم حدّث الموقع. لا تضع بيانات سرية في الشيت المنشور.
